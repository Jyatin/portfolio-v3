## Run Locally

### Prerequisites

- Node.js and npm
- Git

### Setup

```bash
git clone https://github.com/Jyatin/portfolio-v3.git
cd portfolio-v3
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Portfolio RAG Assistant

If you're setting up the RAG assistant, configure the environment variables required by the project before running the ingestion step:

```bash
npm run rag:ingest
```

Check the project configuration and scripts for any additional setup requirements. Never commit API keys, tokens, or other secrets.
